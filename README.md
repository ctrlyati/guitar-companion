# Guitar Companion 🎸

A sleek, mobile-friendly web app for guitarists featuring a drum machine, interactive fretboard, and music theory tools.

## Features

- **Drum Machine / Metronome** - Adjustable BPM (30-240), multiple rhythm patterns, visual beat indicator
- **Interactive Fretboard** - Real-time scale and chord visualization across the neck
- **Music Theory Tools** - Explore scales, modes, and chords in any key
- **Multiple Tunings** - Standard, Drop D, Open G, Open D, DADGAD, and custom tuning support
- **Chords in Key** - See all diatonic chords for the selected key/scale

## Getting Started

Simply open `index.html` in a web browser. No build step or server required.

```bash
# Clone the repository
git clone https://github.com/ctrlyati/guitar-companion.git

# Open in browser
open index.html
```

## Tech Stack

- Pure HTML, CSS, and JavaScript
- [Tailwind CSS](https://tailwindcss.com/) (via CDN)
- Web Audio API for drum sounds

## Usage

1. **Set your tempo** using the BPM slider or +/- buttons
2. **Choose a rhythm pattern** from the dropdown
3. **Select a key and scale/mode** to visualize on the fretboard
4. **Tap chord cards** to see fingerings on the fretboard
5. **Adjust tuning** to match your guitar
